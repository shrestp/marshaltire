What Is a DOT Code?

The DOT code is an alphanumeric code that appears on the sidewall of the tire. This code is sometimes referred to as a serial number. Mandated by the U.S. Department of Transportation, it identifies where a tire was manufactured, specific characteristics about the tire and its age.

The code starts with the DOT designation, followed by a series of letters and numbers. Here’s how to read it

Example Code: DOT H2U1 YC7L 3805

Manufacturing Plant

H2: identifies the plant that manufactured the tire.

Tire Size Code

U1: is the tire size code.

Option Code

YC7L: an optional code that refers to a brand or other characteristics specific to the tire.

Date of Manufacturing

3805: identifies the manufacturing date. The first two digits represent the week and the last two digits represent the year. Therefore, in this example, the tire was manufactured in the 38th week of 2005.
